# Figure sources for "Degree-Ratio Sombor Indices of Chemical Trees"

All six manuscript figures are generated by code in this folder. No figure is hand-drawn or produced by an image-generation tool.

## Run

```bash
python -m pip install -r requirements-figures.txt
python make_all_figures.py
```

Python 3.10 or newer is required. Every figure is written to `output/` twice: as a vector PDF (the version used in the manuscript) and as a 600-dpi PNG.

## What each figure is built from

| Figure | Script | Source of the content | Checks performed by the code |
|---|---|---|---|
| Fig1 | `draw_figures_1_3.py` | the ten chemical edge-degree types $(i,j)$, $1\le i\le j\le 4$ | All 10 types appear exactly once, and every ratio equals $\max/\min$. |
| Fig2 | `draw_fig2_fig4_fig5_fig6.py` | the statements of the partition-hierarchy theorems (diagram only) | None; this is a diagram of theorem statements. |
| Fig3 | `draw_figures_1_3.py` | the witness trees $T_1,T_2$ ($n=9$) and $H_1,H_2$ ($n=16$), built as NetworkX graphs | Each graph is a tree of the right order. Vertex labels come from `G.degree(v)`. The edge-degree counts $m_{ij}$ match the paper. |
| Fig4 | `draw_fig2_fig4_fig5_fig6.py` | the 56-vertex trees $A,B$, built literally as in the proof of the sharp SO–DRSO theorem | Both trees have 56 vertices. $m(A)$ and $m(B)$ match the paper. $\mathrm{SO}(A)=\mathrm{SO}(B)$ and $\mathrm{DRSO}(A)-\mathrm{DRSO}(B)=2\sqrt2-\sqrt{17}$, checked exactly with SymPy. |
| Fig5 | `draw_fig2_fig4_fig5_fig6.py` | `data/exact_enumeration_counts_n4_n20.csv` | The first DRSO–SDD gap is at $n=9$ and the first SO–DRSO gap is at $n=16$. |
| Fig6 | `draw_fig2_fig4_fig5_fig6.py` | `data/bp_c6_c10_loocv.csv` | None beyond reading the CSV. |

Both CSV files are copies of the reference outputs in `results/reference/` of
https://github.com/hanedanelif/degree-ratio-sombor-chemical-trees, which is the code that produces the numbers.
