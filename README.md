# Degree-Ratio Sombor Indices of Chemical Trees — Reproducibility Materials

This repository provides the computational materials associated with the manuscript
**“Degree-Ratio Sombor Indices of Chemical Trees: Ratio Profiles, Structural Discrimination, and Property-Specific QSPR Resolution.”**

It contains the analysis code, processed data used in the manuscript, reference result tables, and automated consistency checks required to reproduce the reported computational results.

## Scope

The repository supports the following analyses:

- exact equality-class enumeration of chemical trees for SO, DRSO/mDRSO, and SDD;
- exact representation of DRSO/mDRSO equality by the six-component degree-ratio profile;
- complete C6–C10 boiling-point fixed-size LOOCV analyses;
- pooled repeated 10×10-fold out-of-fold cross-validation for the size-adjusted boiling-point models;
- categorical carbon-number robustness analysis;
- the size-adjusted descriptor comparison reported in manuscript Table 6;
- 10,000-response-permutation association analyses with plus-one correction and Benjamini–Hochberg adjustment;
- structural-resolution ratios and descriptor-partition representation limits.

## Computational protocol

### Pooled repeated cross-validation

```python
RepeatedKFold(n_splits=10, n_repeats=10, random_state=20260812)
```

All held-out predictions from the 100 validation folds are pooled into a single out-of-fold prediction vector. The reported Q², RMSE, and MAE values are calculated from this pooled vector. Identical fold assignments are used for all compared model specifications.

The integer seed `20260812` is used solely to make the resampling and permutation procedures exactly reproducible; it has no inferential meaning.

### Fixed-size analysis

Complete fixed-size isomer series are assessed by leave-one-out cross-validation (LOOCV).

### Boiling-point response permutation

The complete C6–C10 boiling-point association analysis uses:

- 10,000 response permutations per descriptor-response test;
- the in-sample simple-regression R² as the test statistic;
- `numpy.random.default_rng(20260812)`;
- plus-one correction for permutation p-values;
- Benjamini–Hochberg adjustment within each pre-specified nine-descriptor size family.

## Installation

Create a Python environment and install the required packages:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Reproduce the boiling-point analysis

```bash
python drso_reproducibility.py --mode bp
```

The script recomputes the manuscript-associated boiling-point results and checks them against the reference values included in this repository. An error is raised if the recomputed values differ beyond the stated numerical tolerance.

## Exact chemical-tree enumeration

A shorter verification through order 18 can be run with:

```bash
python drso_reproducibility.py --mode enumeration --n-max 18
```

The complete enumeration through order 20 can be run with:

```bash
python drso_reproducibility.py --mode enumeration --n-max 20
```

The order-20 enumeration is computationally more demanding and may require several minutes or longer depending on hardware. Reference equality-class counts through order 20 are provided under `results/reference/`.

## Rebuild the common QDB.122 panel

The QsarDB data-engineering pipeline requires internet access:

```bash
python src/qsardb_pipeline.py --output data/processed/DRSO_QSPR_master_QDB122.csv
```

The pipeline fixes the common 134-compound D/RI/HC/E panel before modelling, restricts BP to the same identifiers, converts alkane names to hydrogen-suppressed carbon trees, verifies the chemical-tree identities, and computes the pre-specified descriptor panel.

## Automated verification

Run:

```bash
pytest -q
```

The test suite checks:

- manuscript-associated pooled-CV reference values;
- the descriptor comparison reported in Table 6;
- the archived 10,000-permutation exceedance counts used to verify the randomization protocol;
- exact enumeration counts for small chemical-tree orders.

## Computational provenance

The computational history includes earlier exploratory repeated-CV outputs that were superseded by the protocol reported in the manuscript. These exploratory files are not included in the public-facing repository. The selection of the reported protocol and the relationship between the historical and manuscript-associated calculations are documented in `docs/COMPUTATIONAL_PROVENANCE.md`.

## Data provenance

Experimental alkane data originate from QsarDB QDB.122 and the Liu–Cai–Cao–Li source study cited in the manuscript. The processed data file included here is used only to reproduce the analyses reported in the manuscript. Users should consult QsarDB and the original source for the authoritative experimental records and applicable data-use terms.

The QsarDB density endpoint contains a unit-metadata inconsistency discussed in the manuscript. The numerical values are retained unchanged in the analysis. The source-defined endpoint E is handled conservatively and is not assigned a more specific thermodynamic interpretation than supported by the source documentation.
